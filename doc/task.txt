项目一：AI 驱动的 O2O 智慧生活平台 | 后端开发 | 2025.8 - 2025.11
    项目简介：面向商户与用户的聚合交易系统，涵盖商户检索、高并发优惠券秒杀、智能助手等核心业务模块。
    高并发查询与秒杀： 设计 Caffeine + Redis 多级缓存，布隆过滤器拦截非法请求，Canal 订阅 binlog 异步刷新保证缓存最终一致性；秒杀链路基于 Redis + Lua 实现预扣库存与一人一单（集群模式 hash tag 路由同 slot），Kafka 异步落库削峰，消费端幂等表 + 本地消息表保证最终一致，失败补偿回滚库存。
    AI智能助手赋能Agent： 基于 LangGraph4j 状态图编排 ReAct Agent，以条件边约束行为边界并兜底转人工；通过 Function Call 打通订单查询、退款、核销等工具实现"推理→行动→观察"多轮闭环，检索能力（RAG 混合检索 / 知识图谱）作为工具节点由图路由自主调度。
    可控性与安全： 敏感动作强制用户二次确认 + 业务层权限校验，防止越权；输入做 prompt 注入检测与 PII 脱敏，输出做幻觉溯源校验，不通过则降级转人工。
    上下文与成本： 采用前缀匹配复用固定系统提示/工具定义前缀，命中 prompt 缓存降低重复计算成本；基于多层导航设计组织上下文——默认只附带摘要与引用，Agent 判断需要时再拉取完整片段，避免一次性灌入全量信息；配合滑动窗口 + 历史摘要压缩、SSE 流式输出、高频意图路由小模型，整体控制单会话成本与首 token 延迟。
